Receba conversas em tempo real, registre vendas e acompanhe os resultados no dashboard.

// FAQ

Perguntas frequentes

Preciso de servidor próprio?
continnumOS roda em container (Docker). Você pode hospedar onde preferir; a documentação traz o passo a passo de deploy com docker-compose.
Como funciona o isolamento entre clientes?
Cada tenant tem seus dados protegidos por Row-Level Security no banco. Um cliente jamais acessa dados de outro, mesmo compartilhando a mesma instância da aplicação.
Consigo usar minha marca?
Sim. O plano White-label permite marca, cores e domínio próprio por cliente. O sistema já nasce sem referências fixas de marca.
Como conecto o WhatsApp?
Via Evolution API: basta escanear o QR Code na configuração da instância. Detalhes na documentação.
Existe cobrança automatizada?
Sim. Há gestão de faturas, integração com gateway de pagamento, suspensão automática por inadimplência e portal de billing para o cliente final.

Pronto para revender atendimento com a sua marca?
